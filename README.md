# AndroidRTC

## WebRTC Live Streaming

An Android client for [crossdesk-server](https://github.com/kunkundi/crossdesk-server).

It is designed to demonstrate WebRTC screen share between androids and/or desktop browsers.

## How To

You need [crossdesk-server](https://github.com/kunkundi/crossdesk-server) up and running, and it must be somewhere that your android can access. (You can quickly test this with your android browser). Modify the host string (in res/values/strings.xml) to the server IP.


## Libraries

### [libjingle peerconnection](https://code.google.com/p/webrtc/)
